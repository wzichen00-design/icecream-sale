## 环境搭建

### 开发工具

| 工具 | 版本要求 | 下载地址 |
|------|----------|----------|
| 微信开发者工具 | >= 1.05.0 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html |
| Node.js | >= 16.0.0 | https://nodejs.org/ |
| VS Code | 任意版本 | https://code.visualstudio.com/ |

### 开发环境配置

1. **安装 Node.js 依赖**
```bash
npm install
```

2. **配置微信开发者工具**
   - 设置 → 编辑器设置 → 勾选「文件保存时自动编译」
   - 设置 → 编辑器设置 → 勾选「文件保存时自动热重载」

3. **开通云开发**
   - 在微信开发者工具中点击「云开发」
   - 按提示开通云开发服务
   - 记录云环境 ID

## 核心模块

### 1. API 服务层 (utils/api.js)

封装所有云函数调用，统一管理接口。

```javascript
const { productService, adminService, getOpenid } = require('../../utils/api');

// 获取商品列表
productService.getProducts({ category: '雪糕', pageSize: 10 });

// 添加商品
productService.addProduct({ name: '老冰棍', spec: '10支/箱', ... });

// 检查管理员权限
adminService.check();
```

### 2. 工具函数 (utils/util.js)

提供常用工具函数。

```javascript
const { formatTime, debounce, showError, showSuccess } = require('../../utils/util');

// 格式化时间
formatTime(new Date()); // "2024-01-01 12:00"

// 防抖函数
debounce(fn, 500);

// 显示提示
showError('操作失败');
showSuccess('操作成功');
```

### 3. 错误处理 (utils/error.js)

统一错误处理机制。

```javascript
const { handleError, withRetry, withTimeout } = require('../../utils/error');

// 处理错误
handleError(error);

// 重试机制
withRetry(fn, 3, 1000);

// 超时控制
withTimeout(promise, 10000);
```

### 4. 配置管理 (utils/config.js)

管理环境配置和常量。

```javascript
const { config, getCloudEnv, getConfig } = require('../../utils/config');

// 获取云环境 ID
getCloudEnv();

// 获取配置项
getConfig('pageSize'); // 10
```

## 开发规范

### 代码规范

1. **命名规范**
   - 变量名：小驼峰 `userName`
   - 函数名：小驼峰 `getUserInfo`
   - 常量名：全大写 `MAX_COUNT`
   - 文件名：小写 `user-info.js`

2. **注释规范**
```javascript
/**
 * 函数说明
 * @param {string} name 参数说明
 * @returns {Promise} 返回值说明
 */
function getUserInfo(name) {
  // 单行注释
}
```

3. **异步处理**
```javascript
// 推荐：async/await
async function loadData() {
  try {
    const res = await api.getData();
    return res;
  } catch (err) {
    console.error(err);
  }
}

// 不推荐：回调嵌套
function loadData() {
  api.getData().then(res => {
    // ...
  }).catch(err => {
    // ...
  });
}
```

### Git 提交规范

```
feat: 新功能
fix: 修复 bug
docs: 文档更新
style: 代码格式调整
refactor: 代码重构
test: 测试相关
chore: 构建/工具相关
```

示例：
```
feat: 添加商品搜索功能
fix: 修复商品列表分页问题
docs: 更新 README 文档
```

## 调试技巧

### 1. 控制台调试

```javascript
// 打印信息
console.log('调试信息', data);

// 打印对象
console.table(arrayData);

// 计时
console.time('加载时间');
// ... 代码
console.timeEnd('加载时间');
```

### 2. 云函数调试

在微信开发者工具中：
1. 点击「云开发」→「云函数」
2. 选择要调试的云函数
3. 点击「云端测试」
4. 输入参数并调用

### 3. 数据库调试

在云开发控制台：
1. 点击「数据库」
2. 选择集合
3. 查看数据、添加/编辑/删除记录

### 4. 网络请求调试

在微信开发者工具调试器中：
1. 点击「Network」标签
2. 查看所有网络请求
3. 查看请求参数和响应数据

## 常见问题

### Q: 云函数调用失败？

检查：
1. 云函数是否已部署
2. 云环境是否已选择
3. 参数格式是否正确

### Q: 数据库操作失败？

检查：
1. 集合是否已创建
2. 安全规则是否配置
3. 权限是否足够

### Q: 图片上传失败？

检查：
1. 云存储是否开通
2. 文件大小是否超限
3. 网络是否正常
