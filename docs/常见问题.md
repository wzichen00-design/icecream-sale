## 环境配置问题

### Q: 如何开通云开发？

**步骤**：

1. 打开微信开发者工具
2. 点击工具栏「云开发」按钮
3. 首次使用会提示开通
4. 填写环境名称
5. 选择套餐（建议选择按量付费）
6. 点击「确定」开通

**注意**：需要小程序管理员权限才能开通。

---

### Q: 如何获取云环境 ID？

**方法一**：云开发控制台

1. 点击「云开发」
2. 点击「设置」→「环境设置」
3. 复制「环境 ID」

**方法二**：云开发控制台首页

环境 ID 会显示在页面顶部。

---

### Q: 如何切换云环境？

**步骤**：

1. 在微信开发者工具中
2. 右键 `cloudfunctions` 文件夹
3. 选择「更多设置」或「当前环境」
4. 选择要使用的环境

---

### Q: 开发环境和生产环境如何区分？

**建议**：

创建两个云开发环境：
- 开发环境：用于日常开发和测试
- 生产环境：用于线上运行

在 `utils/config.js` 中配置：

```javascript
const ENV = {
  dev: {
    cloudEnv: '开发环境ID'
  },
  prod: {
    cloudEnv: '生产环境ID'
  }
};

// 开发时使用 dev，上线前改为 prod
const currentEnv = 'dev';
```

## 云函数问题

### Q: 云函数调用返回空对象 {}？

**原因**：云函数未部署或部署失败。

**解决方案**：

1. 右键云函数文件夹
2. 选择「上传并部署：云端安装依赖」
3. 等待上传成功
4. 重新调用

---

### Q: 云函数调用失败，提示 -501000？

**错误信息**：
```
errCode: -501000
errMsg: FunctionName parameter could not be found
```

**原因**：云函数不存在。

**解决方案**：

1. 确认云函数已上传部署
2. 确认云环境已选择正确
3. 在云开发控制台检查云函数是否存在

---

### Q: 云函数调用超时？

**原因**：
- 云函数执行时间过长
- 数据库查询慢
- 网络问题

**解决方案**：

1. 优化云函数代码
2. 添加数据库索引
3. 减少单次查询数据量
4. 增加超时时间（云函数配置）

---

### Q: 云函数日志如何查看？

**步骤**：

1. 打开云开发控制台
2. 点击「云函数」
3. 选择要查看的云函数
4. 点击「日志」标签
5. 查看调用日志

---

### Q: 如何本地调试云函数？

**步骤**：

1. 右键云函数文件夹
2. 选择「开启云函数本地调试」
3. 在调试窗口输入参数
4. 点击「调用」
5. 查看返回结果和日志

---

## 数据库问题

### Q: 数据库操作失败，提示 -502005？

**错误信息**：
```
errCode: -502005
errMsg: database collection not exist
```

**原因**：数据库集合不存在。

**解决方案**：

1. 打开云开发控制台
2. 点击「数据库」
3. 点击「添加集合」
4. 创建需要的集合（products、config）

---

### Q: 数据库查询很慢？

**原因**：缺少索引。

**解决方案**：

为常用查询字段创建索引：

1. 打开云开发控制台
2. 点击「数据库」→ 选择集合
3. 点击「索引管理」
4. 添加索引

**建议索引**：

products 集合：
- `createTime`（降序）
- `category` + `createTime`

---

### Q: 数据库写入失败？

**可能原因**：

1. 安全规则限制
2. 字段类型不匹配
3. 数据格式错误

**解决方案**：

1. 检查安全规则配置
2. 确认字段类型正确
3. 查看云函数日志定位问题

---

### Q: 如何配置数据库安全规则？

**步骤**：

1. 打开云开发控制台
2. 点击「数据库」→ 选择集合
3. 点击「权限设置」
4. 编辑规则

**推荐配置**：

products 集合：
```json
{
  "read": true,
  "write": false
}
```

config 集合：
```json
{
  "read": false,
  "write": false
}
```

## 权限问题

### Q: 提示「无权限执行此操作」？

**原因**：当前用户不是管理员。

**解决方案**：

1. 获取你的 OpenID：
   - 云开发控制台 → 云函数 → getOpenid → 云端测试

2. 添加管理员：
   - 云开发控制台 → 数据库 → config 集合
   - 编辑 `admins` 文档
   - 在 `adminList` 数组中添加你的 OpenID

---

### Q: 如何初始化管理员？

**方法一**：手动添加

1. 获取你的 OpenID
2. 在 `config` 集合添加记录：
```json
{
  "_id": "admins",
  "adminList": ["你的openid"]
}
```

**方法二**：调用云函数

1. 云开发控制台 → 云函数 → manageAdmin
2. 云端测试，输入参数：
```json
{
  "action": "init"
}
```
3. 点击「调用」

---

### Q: 如何添加其他管理员？

**方法一**：通过管理员设置页面

1. 用管理员账号登录小程序
2. 点击首页右上角 ⚙️ 按钮
3. 进入管理员设置页面
4. 输入要添加的 OpenID
5. 点击「添加」

**方法二**：直接修改数据库

1. 打开云开发控制台
2. 数据库 → config 集合
3. 编辑 `admins` 文档
4. 在 `adminList` 数组中添加新 OpenID

---

### Q: 如何获取其他用户的 OpenID？

**方法**：

1. 让目标用户打开小程序
2. 目标用户进入管理员设置页面
3. 点击「复制 OpenID」
4. 发送给你
5. 你在管理员设置页面添加

## 上传发布问题

### Q: 上传代码失败？

**可能原因**：

1. AppID 不正确
2. 网络问题
3. 代码有错误
4. 包体积超限

**解决方案**：

1. 检查 `project.config.json` 中的 AppID
2. 检查网络连接
3. 检查代码是否有语法错误
4. 检查包体积（主包不超过 2MB）

---

### Q: 审核被拒绝怎么办？

**常见拒绝原因及解决方案**：

| 原因 | 解决方案 |
|------|----------|
| 隐私协议未配置 | 在微信后台配置隐私协议 |
| 服务类目不匹配 | 修改为正确的服务类目 |
| 功能不完整 | 完善功能后重新提交 |
| 存在测试内容 | 移除测试数据 |
| 名称违规 | 修改小程序名称 |
| 截图不清晰 | 重新上传清晰截图 |

---

### Q: 如何查看审核进度？

**步骤**：

1. 登录微信公众平台
2. 管理 → 版本管理
3. 查看审核版本状态

---

### Q: 审核需要多长时间？

**时间**：通常 1-3 个工作日

**注意**：
- 节假日可能延长
- 首次提交审核时间可能较长
- 审核结果会通过微信通知

## 运行时问题

### Q: 图片上传失败？

**可能原因**：

1. 云存储未开通
2. 文件大小超限
3. 网络问题
4. 文件格式不支持

**解决方案**：

1. 确认云存储已开通
2. 压缩图片后上传
3. 检查网络连接
4. 使用支持的格式（jpg、png）

---

### Q: 图片加载很慢？

**原因**：
- 图片文件过大
- 网络问题
- 未使用 CDN

**解决方案**：

1. 压缩图片质量
2. 使用适当尺寸的图片
3. 开启云存储 CDN

---

### Q: 分页加载不正常？

**可能原因**：
- 游标参数错误
- 数据量不足

**解决方案**：

检查分页参数：

```javascript
// 首次加载
productService.getProducts({ pageSize: 10 })

// 加载更多
productService.getProducts({
  lastId: lastId,           // 上一页最后一条记录 ID
  lastCreateTime: lastCreateTime,  // 上一页最后一条记录时间
  pageSize: 10
})
```

---

### Q: 搜索功能不工作？

**可能原因**：
- 搜索关键词为空
- 数据库没有匹配数据
- 正则表达式错误

**解决方案**：

1. 确认搜索关键词不为空
2. 检查数据库是否有数据
3. 查看云函数日志

---

### Q: 小程序白屏？

**可能原因**：
- JavaScript 错误
- 网络请求失败
- 页面渲染错误

**解决方案**：

1. 打开调试器查看错误信息
2. 检查网络请求
3. 检查页面代码

---

### Q: 如何查看运行日志？

**方法一**：开发者工具调试器

1. 点击「调试器」标签
2. 选择「Console」
3. 查看日志输出

**方法二**：真机调试

1. 点击「真机调试」
2. 扫码在手机上打开
3. 在调试器中查看日志
