## 微信后台配置

### 1. 登录微信公众平台

访问 [https://mp.weixin.qq.com](https://mp.weixin.qq.com) 并用管理员微信扫码登录。

### 2. 基本信息设置

**位置**：设置 → 基本设置

#### 小程序名称

1. 点击「小程序名称」→「设置」
2. 填写名称（如：XX雪糕批发）
3. 提交审核（审核时间 1-7 天）

**命名规范**：
- 不能使用通用词、行业词
- 不能使用他人商标
- 建议格式：品牌名 + 业务名

#### 小程序头像

1. 点击「小程序头像」→「修改」
2. 上传 144×144px 图片
3. 图片要求：
   - 格式：png、jpeg、jpg
   - 大小：不超过 2MB
   - 内容：清晰、无水印

#### 小程序简介

1. 点击「小程序简介」→「设置」
2. 填写简介（4-120 字）

示例：
```
XX雪糕批发，提供各类雪糕、冰淇淋、冰棍批发服务，品种齐全，价格实惠，欢迎选购！
```

#### 服务类目

1. 点击「服务类目」→「添加」
2. 选择类目：

| 一级类目 | 二级类目 |
|----------|----------|
| 生活服务 | 百货/超市/便利店 |
| 电商平台 | 综合电商 |

### 3. 隐私协议配置（必须）

**位置**：设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引

#### 配置步骤

1. 点击「配置」
2. 填写以下内容：

**收集信息类型**：
```
我们收集和使用以下用户信息：
1. 微信昵称、头像：用于展示用户身份
2. 图片信息：用于商品图片上传
```

**信息存储**：
```
数据存储于微信云开发服务器，位于中国境内。
```

**隐私政策链接**：
```
如有独立的隐私政策页面，填写链接地址。
如没有，可以填写小程序首页地址。
```

3. 点击「保存」

### 4. 服务器域名配置

**位置**：开发 → 开发管理 → 服务器域名

云开发项目一般自动配置，如需手动配置：

| 域名类型 | 域名地址 |
|----------|----------|
| request 合法域名 | https://api.weixin.qq.com |
| uploadFile 合法域名 | 自动配置 |
| downloadFile 合法域名 | 自动配置 |

## 云开发配置

### 1. 创建生产环境

**位置**：微信开发者工具 → 云开发控制台

1. 点击「设置」→「环境设置」
2. 点击「创建环境」
3. 填写环境名称（如：prod）
4. 选择套餐（建议按量付费）

### 2. 创建数据库集合

**位置**：云开发控制台 → 数据库

创建以下集合：

#### products 集合

1. 点击「添加集合」
2. 输入集合名称：`products`
3. 点击「确定」

#### config 集合

1. 点击「添加集合」
2. 输入集合名称：`config`
3. 点击「确定」

### 3. 配置数据库安全规则

**位置**：云开发控制台 → 数据库 → 选择集合 → 权限设置

#### products 集合规则

```json
{
  "read": true,
  "write": false
}
```

说明：
- `read: true` - 所有人可读
- `write: false` - 禁止前端直接写入

#### config 集合规则

```json
{
  "read": false,
  "write": false
}
```

说明：
- 禁止前端直接读写，只能通过云函数操作

### 4. 创建数据库索引

**位置**：云开发控制台 → 数据库 → 选择集合 → 索引管理

#### products 集合索引

点击「添加索引」，创建以下索引：

**索引 1**：
- 索引名称：`createTime_desc`
- 索引字段：`createTime`（降序）
- 是否唯一：否

**索引 2**：
- 索引名称：`category_createTime`
- 索引字段：
  - `category`（升序）
  - `createTime`（降序）
- 是否唯一：否

### 5. 部署云函数

**位置**：微信开发者工具

#### 选择云环境

1. 右键 `cloudfunctions` 文件夹
2. 选择「更多设置」或「当前环境」
3. 选择生产环境

#### 部署云函数

依次部署以下云函数：

1. **getOpenid**
   - 右键 `cloudfunctions/getOpenid`
   - 选择「上传并部署：云端安装依赖」
   - 等待上传成功

2. **manageAdmin**
   - 右键 `cloudfunctions/manageAdmin`
   - 选择「上传并部署：云端安装依赖」
   - 等待上传成功

3. **productService**
   - 右键 `cloudfunctions/productService`
   - 选择「上传并部署：云端安装依赖」
   - 等待上传成功

### 6. 初始化管理员

**位置**：云开发控制台 → 数据库 → config 集合

#### 获取 OpenID

1. 点击「云函数」→「getOpenid」
2. 点击「云端测试」
3. 点击「调用」
4. 复制返回的 `openid`

#### 添加管理员记录

1. 点击「数据库」→「config」集合
2. 点击「添加记录」
3. 输入以下内容：

```json
{
  "_id": "admins",
  "adminList": ["你的openid"]
}
```

4. 点击「确定」

## 代码配置

### 1. 修改云环境 ID

**文件**：`utils/config.js`

```javascript
const ENV = {
  dev: {
    cloudEnv: '开发环境ID'
  },
  prod: {
    cloudEnv: '生产环境ID'  // 改为生产环境 ID
  }
};

const currentEnv = 'prod';  // 改为 'prod'
```

### 2. 确认 AppID

**文件**：`project.config.json`

```json
{
  "appid": "你的小程序AppID"
}
```

### 3. 更新版本号

**文件**：`project.config.json`

```json
{
  "projectname": "icecream-sale",
  "description": "雪糕批发店小程序 v1.0.0"
}
```

### 4. 代码清理

运行 ESLint 检查：
```bash
npm run lint
```

手动检查：
- 移除所有 `console.log`
- 移除测试代码
- 移除注释掉的代码

## 上传与审核

### 1. 上传代码

**位置**：微信开发者工具

1. 点击工具栏「上传」按钮
2. 填写版本信息：

| 字段 | 内容 |
|------|------|
| 版本号 | 1.0.0 |
| 项目备注 | 首次发布，包含商品展示和管理功能 |

3. 点击「上传」
4. 等待上传完成

### 2. 提交审核

**位置**：微信公众平台 → 管理 → 版本管理

#### 步骤

1. 找到刚上传的开发版本
2. 点击「提交审核」
3. 填写审核信息：

**功能页面**：

| 页面路径 | 功能描述 |
|----------|----------|
| pages/index/index | 首页，展示商品列表，支持搜索和分类筛选 |
| pages/manage/manage | 商品管理页面，管理员可编辑、删除商品 |
| pages/admin/admin | 发布商品页面，管理员可发布新商品 |

**测试账号**（如需要）：
- 如果功能需要登录或特定权限，提供测试账号
- 本项目无需测试账号

**补充材料**：
- 上传小程序截图
- 上传功能演示视频（可选）

4. 点击「提交审核」

### 3. 等待审核

- 审核时间：通常 1-3 个工作日
- 可在「版本管理」查看审核状态
- 审核结果会通过微信通知

#### 审核状态

| 状态 | 说明 |
|------|------|
| 审核中 | 等待审核 |
| 审核通过 | 可以发布 |
| 审核驳回 | 需要修改后重新提交 |

## 发布上线

### 1. 审核通过后

**位置**：微信公众平台 → 管理 → 版本管理 → 审核版本

1. 看到审核通过状态
2. 点击「发布」按钮

### 2. 选择发布方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| 全量发布 | 所有用户立即可用 | 小用户量、功能稳定 |
| 分阶段发布 | 按比例逐步发布 | 大用户量、首次发布 |

**建议首次发布选择分阶段发布**：

| 阶段 | 比例 | 时间 |
|------|------|------|
| 第一阶段 | 10% | 发布当天 |
| 第二阶段 | 30% | 发布第二天 |
| 第三阶段 | 100% | 发布第三天 |

### 3. 发布成功

- 用户可在微信搜索到你的小程序
- 分享链接可正常访问
- 小程序码可正常扫码访问

## 上线后运维

### 1. 监控告警

**位置**：云开发控制台 → 监控告警

#### 配置告警

1. 点击「告警设置」
2. 添加告警规则：

| 指标 | 阈值 | 通知方式 |
|------|------|----------|
| 云函数错误率 | > 5% | 微信通知 |
| 数据库读操作 | > 1000次/分钟 | 微信通知 |
| 云存储容量 | > 80% | 微信通知 |

### 2. 日志查看

**位置**：云开发控制台 → 日志管理

- 查看云函数调用日志
- 查看错误日志
- 导出日志分析

### 3. 数据备份

**位置**：云开发控制台 → 数据库

定期备份数据库：
1. 点击「导出」
2. 选择导出格式（JSON/CSV）
3. 下载备份文件

### 4. 版本更新

#### 更新流程

1. 修改代码
2. 更新版本号
3. 上传新版本
4. 提交审核
5. 审核通过后发布

#### 版本号规范

```
主版本号.次版本号.修订号

例如：
1.0.0 - 首次发布
1.0.1 - 修复 bug
1.1.0 - 新增功能
2.0.0 - 重大更新
```

## 常见问题

### Q: 审核被拒绝怎么办？

**常见拒绝原因**：

| 原因 | 解决方案 |
|------|----------|
| 隐私协议未配置 | 在微信后台配置隐私协议 |
| 服务类目不匹配 | 修改为正确的服务类目 |
| 功能不完整 | 完善功能后重新提交 |
| 存在测试内容 | 移除测试数据 |
| 名称违规 | 修改小程序名称 |

### Q: 上传代码失败？

**检查项**：
1. AppID 是否正确
2. 网络是否正常
3. 代码是否有语法错误
4. 是否有敏感词

### Q: 云函数调用失败？

**检查项**：
1. 云函数是否已部署到生产环境
2. 数据库集合是否已创建
3. 安全规则是否配置正确

### Q: 发布后用户反馈问题？

**处理流程**：
1. 在云开发控制台查看日志
2. 定位问题原因
3. 修复问题
4. 上传新版本
5. 重新提交审核
